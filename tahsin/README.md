# School website and academic calendar

Open `t.html` to view the website. Use the Academic Calendar menu to open `academic-calendar.html`.

The calendar includes month navigation, category filters and a monthly agenda. Full date cells use red for holidays, purple for exams, green for activities and blue for academic events. Exam date ranges skip Friday and Saturday closures.

Calendar entries and weekly closures are samples; replace them with the approved school schedule in `script.js`. Shared styling is in `style.css`. Gallery photos are included in `images/`.
